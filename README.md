# サムネスタジオ

Scratch向けのサムネイルを、ブラウザだけで手軽に作成できる単一HTMLアプリです。

## ファイル構成

- `index.html` — アプリ本体。CSSとJavaScriptを内包しています。
- `README.md` — この説明書

外部のCSSファイルやJavaScriptファイルは必要ありません。`index.html`をブラウザで開くだけで利用できます。

## 主な機能

### デザイン

- Scratch向けテンプレートの切り替え
  - スクール
  - ゲーム実況
  - ノウハウ
  - お知らせ
- アクセントカラー変更
- ラウンド感・シャドウ調整
- ズーム操作
- 1280 × 720のサムネイル作成
- PNG書き出し

### 文字編集

- 見出し・サブコピー・タグの編集
- 追加テキストレイヤーの作成
- 文字レイヤーの削除
- 文字のドラッグ移動
- キャンバス上の文字をクリックして選択
- 改行対応
  - テキスト入力欄でEnterを押して改行
  - 見出しは `|` でも行を分けられます
- 太さ・サイズ・色の変更
- フォント変更
  - Manrope
  - Noto Sans JP
  - BIZ UDPGothic
  - M PLUS 1p
  - Zen Kaku Gothic New
  - DM Mono
- フォントファイルの追加
  - TTF
  - OTF
  - WOFF
  - WOFF2

### 素材・図形

- 画像のアップロード
- 画像のドラッグ移動
- NEWステッカーの移動・削除
- 図形の追加
  - 円
  - 四角形
  - 三角形
  - ひし形
  - 星
  - 矢印
- 図形の移動・選択・削除

### 手書き

- キャンバス上に手書き
- ブラシサイズ変更
- ペンの色変更
- 消しゴム
- 手書き内容の全消去

## 使い方

1. `index.html`をブラウザで開きます。
2. 初期状態は空のキャンバスです。
3. すぐ作り始める場合は、右側のテンプレートを選択します。
4. 文字を編集する場合は、キャンバス上の文字をクリックするか、右側の「文字」タブを開きます。
5. 文字や画像、図形はキャンバス上でドラッグして移動できます。
6. 完成したら右上の「PNGを書き出す」をクリックします。

## クイック操作

ChromebookやWindowsでは、以下のキーを使用します。

| 操作 | ショートカット |
| --- | --- |
| 文字編集を開く | `Ctrl + K` |
| 元に戻す | `Ctrl + Z` |
| 選択中の文字・素材を削除 | `Delete` / `Backspace` |

文字をクリックしたときは、選択と編集パネルの表示だけが行われます。入力欄へ自動フォーカスしたり、画面を編集欄まで自動スクロールしたりしません。

## カスタムフォントについて

追加したフォントは、現在開いているブラウザセッション内で使用できます。ページを再読み込みすると、追加したフォントは再度読み込む必要があります。

## 技術情報

- HTML / CSS / JavaScriptのみ
- ビルドツール不要
- ローカルファイルとして実行可能
- Canvas APIによるPNG出力
- File API / FontFace APIによる画像・フォント読み込み
- Pointer Eventsによるドラッグ移動と手書き入力
